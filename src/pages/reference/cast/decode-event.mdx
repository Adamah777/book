## cast decode-event

Decode event data

With `--sig`, DATA contains only the encoded non-indexed event data, without
topics.
Pass `--topics` to also decode indexed parameters and print all parameters in
declaration
order. Without topics, indexed parameters are skipped. Indexed arrays, tuples,
strings,
and bytes are returned as hashes; their original values cannot be recovered.

Examples:
- cast decode-event --sig "Transfer(address indexed from, address indexed to,
uint256
  value)" $DATA
- cast decode-event --sig "Transfer(address indexed from, address indexed to,
uint256
  value)" --topics $TOPIC0,$TOPIC1,$TOPIC2 $DATA
- cast decode-event $DATA (topic0-prefixed data; looks up the signature)

Usage: cast decode-event [OPTIONS] <DATA>

Arguments:
  <DATA>
          The event data to decode. Use 0x for events with only indexed
          parameters

Options:
      --sig <SIG>
          The event signature. If none provided then tries to decode from local
          cache or [https://4byte.sourcify.dev](https://4byte.sourcify.dev)
          
          [alias: --event-sig]

  -t, --topics <TOPICS>
          The log topics, including topic0 for non-anonymous events, in log
          order.
          
          Repeat the flag or separate topics with commas. Requires --sig with
          indexed parameters marked explicitly. Anonymous events do not have a
          signature topic.

  -h, --help
          Print help (see a summary with '-h')

  -j, --threads <THREADS>
          Number of threads to use. Specifying 0 defaults to the number of
          logical cores
          
          [alias: --jobs]

      --profile <PROFILE>
          The configuration profile to use

Display options:
      --color <COLOR>
          The color of the log messages

          Possible values:
          - auto:   Intelligently guess whether to use color output (default)
          - always: Force color output
          - never:  Force disable color output

      --json
          Format log messages as JSON

      --md
          Format log messages as Markdown

  -q, --quiet
          Do not print log messages

  -v, --verbosity...
          Verbosity level of the log messages.
          
          Pass multiple times to increase the verbosity (e.g. -v, -vv, -vvv).
          
          Depending on the context the verbosity levels have different meanings.
          
          For example, the verbosity levels of the EVM are:
          - 2 (-vv): Print logs for all tests.
          - 3 (-vvv): Print execution traces for failing tests.
          - 4 (-vvvv): Print execution traces for all tests, and setup traces
          for failing tests.
          - 5 (-vvvvv): Print execution and setup traces for all tests,
          including storage changes and
            backtraces with line numbers.
